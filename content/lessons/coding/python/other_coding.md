## A few habits worth building early

- **Read error messages fully before reacting.** The exception type
  and the last line of the traceback usually tell you exactly what
  went wrong.
- **Keep functions small and named for what they do.** A function
  that's hard to name in a few words is usually doing too much.
- **Use the standard library before reaching for a package.** Modules
  like `collections`, `itertools`, and `datetime` solve a surprising
  number of "how do I..." questions.
