# AI Engineering Curriculum Import

The Guides tab includes lesson Markdown from [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch), imported from its `phases/*/*/docs/en.md` files. ## Refreshing the content

The importer clones the source repository when no checkout is supplied:

```bash
python3 scripts/import_ai_eng_curriculum.py
```

For an offline or repeatable refresh, point it at an existing checkout:

```bash
python3 scripts/import_ai_eng_curriculum.py --source-dir /path/to/ai-engineering-from-scratch
```

The importer regenerates `content/lessons/phases/`, copies the Markdown lessons to `frontend/content/phases/`, and rebuilds `frontend/content/curriculum.json`.

## Scope

The AI Engineering phase curriculum is the app's only learning track. It includes supporting foundations such as Python environments, probability, statistics for machine learning, linear algebra, and calculus when those topics are needed for AI/ML. These materials remain inside the AI Engineering curriculum; they are not exposed as separate programming or statistics tracks.

The app indexes lesson Markdown on backend startup. The browser Guides view loads the static frontend copy directly. Chat responses are generated by the AI Engineering tutor prompt; the current app does not perform semantic retrieval across all lesson files.
